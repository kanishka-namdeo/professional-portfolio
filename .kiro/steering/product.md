# Product Overview

This is a professional portfolio website for Kanishka Namdeo, a Product Manager with 9+ years of experience in SaaS, mobility, and AI products.

## Purpose
- Showcase professional experience and achievements
- Display product management work and case studies
- Provide contact information and availability status
- Demonstrate technical capabilities through open source contributions

## Key Features
- Single-page application with smooth scrolling navigation
- Responsive design optimized for all devices
- SEO-optimized with structured data (JSON-LD schemas)
- Accessibility-compliant with ARIA labels and semantic HTML
- Dark/light theme support
- Analytics integration via Vercel Analytics

## Target Audience
- Recruiters and hiring managers
- Potential clients for product management consulting
- Professional network and industry peers

## Deployment
- Static site export for GitHub Pages or similar hosting
- Configured for custom domain: kanishkanamdeo.com
- Production-ready with security headers and performance optimizations
