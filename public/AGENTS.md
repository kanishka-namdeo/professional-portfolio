# public/ AGENTS.md

## Purpose
Static assets served publicly without build-time processing. Contains images, icons, fonts, PWA manifests, SEO metadata files, and other web-accessible resources.

## Ownership
- **Scope**: Publicly served static files
- **Parent**: Root AGENTS.md

## Local Contracts
- All files in this directory are served at root path `/filename` or `/subdirectory/`
- Hand-written URLs inside these files (canonical, meta-refresh, sitemap, robots, llms.txt link lists) must be absolute `https://kanishkanamdeo.com/...` — root-relative paths 404 on the GitHub Pages project-site mirror, which deploys under a basePath
- Prefer WebP for images; use JPG/PNG only when transparency or compatibility requires
- Keep individual assets under 500KB when possible
- Favicon and icon files must maintain consistent brand identity
- PWA manifest.json must stay in sync with icon files (icon-192.png, icon-512.png)
- SEO files (robots.txt, sitemap.xml, rss.xml) must reference correct production URLs
- `robots.txt` and `sitemap.xml` are hand-maintained: CI/deploy must not regenerate them (generators would drop the AI-crawler allow-list in robots.txt and omit `/case-study/rentlz` and `/llms.txt` from the sitemap)
- `sitemap.xml` contains only real routes (no hash fragments): `/`, `/case-study/rentlz`, `/field-log`, `/llms.txt`; bump `lastmod` when content changes (last 2026-09-16)
- `robots.txt` blocks aggressive SEO crawlers, allows AI crawlers; no Crawl-delay directives
- `case-study-rentlz.html` is a noindex meta-refresh redirect stub (absolute URL target) to the themed `/case-study/rentlz` route, kept for old backlinks; the Article schema and tenure/metrics content live on the route, not here
- `llms.txt` describes the single-page field log; follow the llmstxt.org convention (H1 = site title, blockquote one-liner, markdown links with absolute URLs). Its link list (case study, field-log page, field-log.pdf) must stay in sync with real routes, and its Key Achievements/Featured Projects must cover ALL five eras including the agents era (Flipr · Cognium · AvloAI). It says "Deployed on Vercel" — that is correct (production is Vercel at kanishkanamdeo.com; the Pages workflow deploys a secondary mirror)
- `rss.xml` is hand-maintained from `data/ledger.ts` and must contain an item for EVERY `ledgerRepos` entry plus every `writing` entry (dates are year-precision for repos → Jan 1 of that year); it was last regenerated 2026-09-16 after 6 repos went missing
- `field-log.pdf` is linked from End of Trail ("Download the field log (PDF)", `download` attribute) and from llms.txt (NOT the sitemap, which lists only real routes); the PDF itself is generated by a separate workstream — the href is the contract

## Work Guidance
- Add new images to the appropriate subdirectory (projects/, recordings/, map/)
- Update manifest.json when adding/updating PWA icons
- Regenerate OG image (og-image.jpg) when site branding changes
- Use descriptive filenames with kebab-case
- Project screenshots ship pre-optimized WebP (≤2560w, q82 via `scripts/optimize-images.mjs`; current: agent-canvas 1280w, pi-dash 2560w, thetell 2560w — their intrinsic sizes are pinned in `data/camps.ts` `screenshotWidth`/`screenshotHeight`) — the static export serves them unoptimized, so raw oversized PNGs must not be committed
- Map data goes in map/ subdirectory; `map/contours.svg` is the LCP image and is regenerated (dieted) by `pnpm run map` — never hand-edit or commit the unsimplified output

## Verification

- Confirm favicon displays in browser tab
- Validate manifest.json via Chrome DevTools Application panel
